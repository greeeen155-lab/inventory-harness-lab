# 05. 디자인 확정본

> Phase 5 · 확정 시안: `mockups/final.html` (검색대 구조 + 보라 팔레트)
> 기준: [03-scenarios.md](./03-scenarios.md) 설계 원칙 P1~P12, [04-engagement.md](./04-engagement.md) E1~E3

## 1. 방향

**시안 2 구조(홈 = 검색 + 재고 목록, 동작은 ＋ 버튼) + 시안 3 팔레트(보라 그라디언트).**

| 항목 | 결정 | 근거 |
|---|---|---|
| 홈 | 재고 목록. 최상단 검색창 고정 | 조회가 가장 잦고, P2는 검색만 한다 (S10) |
| 하단 탭바 | **없음** | 목록을 길게 보여주기 위해 |
| 동작 진입 | 우하단 ＋ → 액션 시트 | 입고·출고·발송·반영·팝업을 한 곳에 |
| 거점 전환 | 홈 상단 세그먼트 필터 | 탭바가 없으므로 |
| 유통기한 | **모든 화면에 날짜로 노출** | FEFO가 핵심 기능인데 배지만으로는 부족 |
| 배포 폭 | 모바일 우선. PC에서는 리스트가 표로 펴짐 | 같은 화면, 다른 폭 |

### 세 가지 시각적 원칙
1. **날짜는 숨기지 않는다.** 로트는 `SKU × 거점 × 유통기한`이므로 화면 어디서든 이 셋이 함께 보인다
2. **상태는 색만으로 말하지 않는다.** 임박/만료/지연은 배지 글자를 함께 쓴다
3. **입력 화면은 장식하지 않는다.** 그라디언트는 홈 헤더와 주 버튼에만. 입력 영역은 흰 바탕 + 굵은 테두리

## 2. 색상 토큰

```css
/* Primary */
--acc:        #5B21B6;   /* 기본 보라 — 버튼, 강조 숫자, 활성 상태 */
--acc-2:      #7C3AED;   /* 그라디언트 상단 */
--acc-soft:   #F4F0FD;   /* 강조 배경 (선택된 필터, 요약 바) */
--acc-line:   #E2D9F5;   /* 강조 테두리 */
--acc-grad:   linear-gradient(160deg, #7C3AED, #5B21B6);

/* Text & surface */
--ink:        #221D33;   /* 본문 */
--sub:        #8B859C;   /* 보조 텍스트, 단위 */
--line:       #EEEAF5;   /* 구분선 */
--bg:         #FFFFFF;
--bg-dim:     #FAF9FC;   /* 가용 제외 영역(배송중·팝업) */

/* Status — 재고 상태 */
--amber:      #B45309;  --amber-bg: #FFF6E9;   /* 임박 */
--red:        #B91C1C;  --red-bg:   #FDECEC;   /* 만료 · 지연 */
--ok:         #0F7B45;  --ok-bg:    #EEF7F1;   /* 정상 */
```

**상태 색 사용 규칙**

| 상태 | 색 | 배지 문구 | 판정 기준 |
|---|---|---|---|
| 정상 | 초록 | `정상` | 경고 임계일 밖 |
| 임박 | 앰버 | `임박` + 남은 일수 | 상품별 `expiry_alert_days` 이내 |
| 만료 | 빨강 | `만료` + 지난 일수 | 유통기한 < 오늘 |
| 지연 | 빨강 | `지연` | 배송 중 7일 초과 |
| 이동 | 보라 | `이동` `진행` | 배송 중 / 팝업 진행 |

> 색맹 사용자를 고려해 **배지 텍스트 없이 색만 쓰는 표현은 금지**한다.

## 3. 타이포 · 숫자

| 용도 | 크기/굵기 | 비고 |
|---|---|---|
| 대표 수량 (가용) | 40px / 800 | `letter-spacing:-.035em` |
| 로트 수량 | 17px / 800 | |
| 유통기한 날짜 | 13.5px / 800 | **`font-variant-numeric: tabular-nums`** |
| 상품명 | 13px / 700 | |
| 보조(거점·남은일수) | 11px / 400, `--sub` | |
| 배지 | 9.5px / 800 | |

- **모든 수량·날짜에 `tabular-nums`를 적용한다.** 목록에서 자릿수가 흔들리면 비교가 안 된다
- 유통기한은 항상 `YYYY-MM-DD` 형식. 축약하지 않는다
- 남은 기간은 사람 말로: `23일`, `1년 7개월`, `8일 지남`

## 4. 컴포넌트 명세

### 4.1 `<SearchHeader>` — 홈 최상단 고정
- 배경 `--acc-grad`, 흰 텍스트
- 1행: `전체 24 SKU · 가용 4,120개`
- 2행: 검색 입력 (반투명 흰 배경)
- 스크롤 시 검색 입력만 남기고 축소(sticky)

### 4.2 `<TodoBanner>` — 오늘 할 일 (E2)
- 얇은 한 줄. 배경 `--amber-bg`
- `⚠ 오늘 할 일 3 · 풀필 C 미반영 · 배송 3건 ›`
- 탭하면 할 일 상세로. **항목이 0이면 렌더하지 않는다**
- 포함 항목은 **세 종류로 고정**: 풀필먼트 미반영 / 미확인 배송(7일 초과) / 만료 재고

### 4.3 `<FilterSegment>` — 거점·상태 필터
- 가로 스크롤 칩. `전체 | 임박 N | 만료 N | 📍자사창고 | 📍풀필A | 📍풀필B | 📍팝업`
- 선택 시 `--acc-soft` 배경 + `--acc` 텍스트 + 800 굵기
- 임박·만료 칩은 앰버 계열로 상시 구분

### 4.4 `<StockRow>` — 재고 목록 한 줄
```
강아지 치즈 간식 200g              340
자사창고 120 · 풀필 220            가용
[임박] 2026-09-10 · 23일 · 풀필A 30개
```
- 3행 구조: 상품명 / 거점 요약 / **가장 임박한 로트(배지 + 날짜 + 남은일수 + 거점 + 수량)**
- 우측: 가용 수량(18px/800) + `가용` 라벨
- 임박·만료 로트가 없으면 3행은 `[정상] 최근 유통기한` 표시
- 탭 → 상품 상세

### 4.5 `<LotCard>` — 로트 카드 (상품 상세의 핵심)
```
┌──────────────────────────┐
│ 2027-03-31          240  │
│ 1년 7개월·거점 2곳  [2순위]│
├──────────────────────────┤
│ 📍 자사창고         120개 │
│ 📍 풀필먼트 A       120개 │
├──────────────────────────┤
│ ▓▓▓▓▓▓▓▓▓░░  (잔여 기간) │
└──────────────────────────┘
```
- **로트 = 거점 × 유통기한.** 카드는 날짜로 묶되 내부에 거점별 수량을 반드시 나열
- 순위 배지(`1순위`·`2순위`)로 **FEFO 출고 순서**를 명시
- 임박 로트는 카드 테두리 `--amber` + 배경 `#FFFDF8`
- 하단 막대: 전체 유통기간 대비 잔여 비율 (장식이 아니라 임박도 시각화)

### 4.6 `<ViewToggle>` — 유통기한순 / 거점순
- 상품 상세 상단 2택. "언제 만료되나"와 "어디 있나"는 다른 질문이므로 정렬을 바꾼다
- 거점순: 거점 카드 안에 로트를 나열 (구조가 뒤집힘)

### 4.7 `<ActionFab>` + `<ActionSheet>`
- 우하단 고정 `＋`. 그라디언트 + 그림자
- 시트 항목 5개 고정: 입고 · 출고 · 풀필먼트 발송 · 풀필먼트 일일 반영 · 팝업 반출/정산
- 시트는 아래에서 올라오고, 바깥 탭 또는 아래로 스와이프로 닫힘

### 4.8 `<LocationChip>` — 거점 선택 (입고·출고 상단)
```
┌──────────┬──────────┐
│ 받는 곳   │ 사유      │
│📍자사창고⌄│ 입고 ⌄    │
└──────────┴──────────┘
```
- 입고: `받는 곳` + `사유(PURCHASE/RETURN/OTHER)`
- 출고: `빼는 곳` + `이 거점 보유 N개`
- **기본값은 자사창고**. 기본값이 맞으면 손을 대지 않는다 (P1의 3탭 원칙)

### 4.9 `<ExpiryKeypad>` — 유통기한 6자리 입력 (E1)
- 큰 입력 필드: `2 7 0 3 3 1` (자간 넓게, tabular-nums)
- 바로 아래 해석 결과: `→ 2027-03-31 · 1년 7개월 남음`
- 최근 사용 기한 칩 3개 + `2703 = 말일` 안내
- 커스텀 숫자 키패드 (`＋기한` 키로 같은 상품에 로트 추가, `⌫`)
- **검증**: 과거 날짜 경고 / 10년 초과 경고 / 6자리 미만 저장 불가

### 4.10 `<AllocationPreview>` — 자동 배분 결과
- 수량 입력 시 실시간으로 로트 카드 목록 표시
- 각 카드: 날짜 + `📍거점 · 보유 N · 전부 사용/N개만 사용` + 배지
- **배분 방향이 화면마다 다르다** — 제목과 설명 문구로 반드시 구분한다

| 화면 | 제목 | 설명 |
|---|---|---|
| 출고 | 자동 선택 — 유통기한 빠른 순 | 임박한 재고부터 내보내 폐기를 줄입니다 |
| 풀필먼트 발송 | 보낼 로트 — **유통기한 늦은 순** | 풀필먼트는 도착·판매까지 오래 걸려, 기한이 넉넉한 재고를 보냅니다 |

- 발송에서 임박 로트가 배분에 섞이면(재고 부족 시) 해당 줄을 앰버로 강조하고 **⚠ 임박분이 포함됐습니다**를 붙인다
- `변경` 탭 → 수동 선택 모드 + **사유 입력 필수** (출고 화면)

### 4.11 `<BulkInputRow>` — 다건 입력 (S5, S9)
```
강아지 치즈 간식 200g          [ 7 ]
150 → 143 · 2026-09-10에서 차감
```
- 왼쪽: 상품명 + 현재→변경 후 + **차감될 로트 날짜**
- 오른쪽: 숫자 입력 박스 (60px 이상, 2px 보라 테두리, 0이면 회색)
- 상단 필터: `최근 움직임 | 전체 | 입력한 것`
- 하단 요약 바(`입력 3건 · 총 12개 차감`) + 고정 저장 버튼

### 4.12 `<SettlementSentence>` — 역산 확인 (P8, E3)
- 배경 `--acc-soft`, 테두리 `--acc-line`
- 숫자를 굵은 보라로 강조한 **문장**:
  > 160개를 가져갔고 **42개**가 돌아왔습니다.
  > 차감 118개 중 시식·증정 **5개**를 빼고 **113개를 판매로 기록**합니다.
- 아래 KPI 4칸(반출/판매/시식/반입) + 상품별 소진율 막대

## 5. 인터랙션 규칙

| 상황 | 동작 |
|---|---|
| 저장 | **확인 다이얼로그 없음.** 저장 후 다음 입력 상태로 복귀 (P1) |
| 저장 직후 | 상단에 얇은 확인 줄 1.5초 노출. 화면 전환 없음 |
| 잘못 입력 | 이력 화면 최상단에서 `취소` (상쇄 기록 생성, F10) |
| 다건 입력 저장 | 하단 고정 버튼. 스크롤과 무관하게 항상 보임 |
| 수량 입력 | 탭하면 숫자 키패드. 기존 값은 전체 선택되어 덮어쓰기 쉬움 |
| 음수 재고 | 저장 버튼 비활성 + 해당 행에 사유 표시 |
| 로딩 | 스켈레톤 대신 이전 값 유지 + 상단 얇은 진행선 |
| 팝업 정산 확정 | 2단계(입력 → 문장 확인). 확정 후에도 되돌리기 가능 |

**터치 영역**: 모든 탭 대상 최소 44×44px. 수량 입력 박스는 높이 40px 이상.

## 6. 반응형

| 폭 | 레이아웃 |
|---|---|
| ~480px (폰) | 단일 컬럼. FAB 우하단. 다건 입력은 세로 리스트 |
| 481~900px (태블릿) | 단일 컬럼 유지, 좌우 여백 확대. 다건 입력 2열 |
| 901px~ (PC) | **좌측 고정 메뉴(180px)** 등장 + 본문. 다건 입력은 **표**로 펼쳐짐 |

- PC에서 `<BulkInputRow>`는 `상품 / 현재 / 입력 / FEFO 차감`이 한 줄인 테이블이 된다
- **별도 화면을 만들지 않는다.** 같은 컴포넌트가 CSS 컨테이너 쿼리로 형태를 바꾼다
- PC에서는 `Tab`으로 다음 수량 칸, `Enter`로 저장

## 7. 접근성

- **색 + 글자 병기**: 모든 상태 배지에 텍스트 (`임박` `만료` `지연`)
- 본문 대비 4.5:1 이상. 보라 `#5B21B6` on 흰색 = 8.6:1 ✓
- 앰버 `#B45309` on `#FFF6E9` = 5.9:1 ✓ / 빨강 `#B91C1C` on `#FDECEC` = 6.4:1 ✓
- **한글 IME**: 검색은 `compositionend` 이후 질의. 조합 중 입력이 잘리지 않게
- 숫자 입력 필드는 `inputmode="numeric"` — 모바일에서 숫자 키패드 강제
- 포커스 링을 지우지 않는다 (`--acc` 2px outline)
- 스크린리더: 로트 카드는 `2027년 3월 31일 만료, 자사창고 120개, 출고 2순위`로 읽히도록 `aria-label` 구성
